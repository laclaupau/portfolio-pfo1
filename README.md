# Portfolio — Paula

## PFO1 — Landing de portfolio

Landing page personal desarrollada como parte de la PFO1 de la materia Desarrollo Front-End en la Tecnicatura en Desarrollo de Software.

El objetivo del proyecto es presentar mi perfil profesional, combinando
educación, creatividad, diseño instruccional, experiencias de aprendizaje
y desarrollo de tecnologías digitales.

La landing incluye:

- Presentación personal.
- Perfil profesional.
- Habilidades educativas y tecnológicas.
- Tecnologías frontend.
- Sección personal.
- Formulario de contacto.
- Enlace visible al perfil público de GitHub.
- Diseño responsive.
- Animaciones y transiciones.
- Consideraciones de accesibilidad.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3

- Google Fonts
- Responsive Design
- Accesibilidad web
- Git / GitHub



## Diseño

La interfaz busca transmitir una identidad humana, editorial y experimental.


### Maquetación

Utilicé CSS Grid para organizar las tarjetas de habilidades y las principales
estructuras de dos columnas.

Utilicé Flexbox para elementos que requieren distribución lineal, como:

- navegación;
- botones;
- etiquetas de habilidades;
- footer;
- elementos internos de las tarjetas.


### Responsive Design

La interfaz utiliza:

- `clamp()` para tamaños fluidos;
- unidades relativas;
- CSS Grid;
- media queries;
- diseño mobile-first en los componentes principales.

La navegación se simplifica en pantallas pequeñas y las tarjetas pasan
de cuatro columnas a dos y finalmente a una columna.

### Accesibilidad

Se utilizaron:

- HTML semántico;
- `aria-label` en elementos de navegación relevantes;
- labels asociados a todos los campos del formulario;
- estados `:focus`;
- enlaces con nombres descriptivos;
- `prefers-reduced-motion` para personas que prefieren reducir las animaciones.

## Autoría

El proyecto fue desarrollado como una producción personal, utilizando
herramientas de IA como apoyo durante el proceso de ideación, revisión y
desarrollo.

### Uso de Inteligencia Artificial

Para el desarrollo de este proyecto utilicé ChatGPT — GPT-5.6.

**Uso:** utilicé IA como asistente para explorar decisiones de estructura,
organización del HTML semántico, estilos CSS, responsive design, accesibilidad, animaciones y selección de tecnologías frontend relevantes para el mercado.

**Plan utilizado:** plan gratuito.


### Revisión y adaptación humana

El código generado con asistencia de IA no fue utilizado de manera
automática sin revisión.

Revisé y adapté:
- las consideraciones de accesibilidad;
- la animación y su comportamiento con `prefers-reduced-motion`.

Las decisiones de contenido y diseño responden a mi propio perfil profesional
y a los objetivos de la PFO1.

No utilicé IA para generar imágenes para este proyecto.
